Curriculum

7시간 · 4개 모듈 · 자동화 시스템 완성 여정

THINK(M1·M2)에서 환경과 프롬프트 기반을 다지고, BUILD(M3)에서 스킬·에이전트를 만들며, SHIP(M4)에서 나만의 플러그인을 배포합니다.

THINK M1 · M2 → BUILD M3 → SHIP M4
Think 1.0H
Module 1

AI 도구 설치 & 프로젝트 구성

Claude Code·Codex·Claude Web 3가지 도구를 설치·세팅하고 첫 AI 프로젝트를 구성합니다. 비개발자도 막힘없이 작업 환경을 갖추는 것이 목표입니다.

  • ▸Claude Code 설치 및 환경 세팅 (20분)
  • ▸Claude Web 가입 및 Project 구성 (15분)
  • ▸Codex 설치와 기본 사용법 (10분)
  • ▸나만의 첫 AI 프로젝트 구성 실습 (15분)
RESULT

3가지 AI 도구가 모두 동작하는 본인 작업 환경 + 첫 프로젝트 생성 완료.

Think 1.5H
Module 2

프롬프팅 방법 & 법령 MCP 실습

업무에 통하는 구조적 프롬프트 설계 원칙을 익히고, MCP 개념을 이해한 뒤 법령 MCP를 연결·활용하는 실전 프롬프팅을 수행합니다.

  • ▸업무에 통하는 프롬프트 설계 원칙 (25분)
  • ▸역할·맥락·제약 기반 구조적 프롬프팅 (25분)
  • ▸MCP(Model Context Protocol) 개념 이해 (15분)
  • ▸법령 MCP를 활용한 실전 프롬프팅 실습 (25분)
RESULT

외부 데이터·도구를 AI와 연결해 활용하는 실전 패턴 체득 + 본인 업무용 프롬프트 라이브러리 초안.

Build 2.0H
Module 3

스킬과 에이전트 개발

Skill과 Agent의 개념·차이·활용 시점을 이해하고, 반복 업무를 자동화하는 본인 전용 Skill 1개와 역할별 Agent 1개를 직접 개발합니다.

  • ▸Skill과 Agent의 개념·차이·활용 시점 (25분)
  • ▸반복 업무 자동화를 위한 Skill 설계·개발 (45분)
  • ▸역할별 Agent 정의와 조율 (35분)
  • ▸본인 업무 맞춤 Skill·Agent 통합 점검 (15분)
RESULT

나만의 Skill 1개 + Agent 1개 직접 구현 완료. '도구 사용자'에서 'AI 시스템 제작자'로 전환.

Ship It! 2.5H
Module 4

플러그인 이론 & 나만의 플러그인 개발

Claude Code 플러그인의 구조·동작 원리를 이해하고, 선언형 멀티에이전트 플러그인(DMAP) 방식으로 업무 특화 플러그인 1종을 설계·구현·배포까지 완성합니다. M3의 Skill·Agent를 재사용합니다.

  • ▸플러그인 구조·동작 원리 (35분)
  • ▸업무 특화 플러그인 설계 (30분)
  • ▸업무 특화 플러그인 구현 (50분 · M3 재사용)
  • ▸플러그인 배포 + 최종 산출물 발표·피드백 (35분)
RESULT

본인 업무에 즉시 적용 가능한 AI 플러그인 1종 완성·배포 + 강사 검증을 받은 산출물 확보. "We shipped it!"
